## 我正在做的项目与 Skills

### [全息闪卡工坊](https://github.com/yzhe3778-ai/ruoyu-holo-card-studio)

把素材做成带视差、镭射和闪星效果的交互卡片，输出工程、模型、渲染图和交互网页。我主要完善视觉预设、批量续跑、素材校验与交付保护。

这是基于 [EverettFish / holo-card-studio](https://github.com/EverettFish/holo-card-studio) 的个人增强版，保留上游署名与原 MIT 许可。

### [导演级视频拉片 Skill](https://github.com/yzhe3778-ai/director-lapian-skill)

从视频抽帧、声音和镜头证据开始，输出图文拉片报告、导演分析和滚动展示视频，让参考片能沉淀成可复用的创作方法。MIT 许可。

### [Seedance 剧本与分镜设计 Skill](https://github.com/yzhe3778-ai/seedance-script-designer)

将创意或剧本整理成镜头、关键帧、视频提示词和素材规划，连接剧本设计与实际 AI 视频生产。公开仓库，使用和分发条件以仓库说明为准。

### [小红书虚拟产品运营框架](https://github.com/yzhe3778-ai/xiaohongshu-virtual-product-operations)

围绕一个人群、一个具体问题和一个交付物，整理选品、定位、内容测试与转化复盘。MIT 许可。
